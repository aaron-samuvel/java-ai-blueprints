# Glossary

| Term | Meaning |
|---|---|
| **A2A** | Agent-to-Agent protocol: agents discover and call each other over a standard interface |
| **Advisor (Spring AI)** | Interceptor around `ChatClient` calls (`CallAdvisor` / `StreamAdvisor`) |
| **Arconia** | Dev Services for Spring Boot: starts local infra (e.g. Ollama, Postgres) automatically |
| **ChatMemory** | Spring AI abstraction that stores conversation history |
| **Detokenise** | Swap vault tokens back to the original values |
| **Docling** | Document parsing toolkit (PDF/Office to structured text) used for RAG ingestion |
| **Embabel** | JVM agent framework based on goal-oriented action planning |
| **FinOps** | Financial operations: managing cloud and AI spend |
| **GOAP** | Goal-Oriented Action Planning: the planner picks actions whose effects reach a goal |
| **HITL** | Human-in-the-loop: the workflow pauses for human approval |
| **J-AIDLC** | Java AI Development Lifecycle, the handbook's 7-stage lifecycle |
| **JSqlParser** | Java SQL parser, used to validate generated SQL |
| **LangGraph4j** | Java port of LangGraph: stateful agent graphs |
| **MCP** | Model Context Protocol: standard for exposing tools and resources to models |
| **NL2SQL** | Natural language to SQL |
| **OODA** | Observe-Orient-Decide-Act loop |
| **OpenInference** | OpenTelemetry semantic conventions for LLM traces |
| **pgvector** | Postgres extension for vector similarity search |
| **PII** | Personally Identifiable Information (email, phone, PAN, Aadhaar, card number…) |
| **RAG** | Retrieval-Augmented Generation |
| **Reserve-call-commit** | Budget pattern: reserve an estimate, call, then commit the actual cost |
| **Stub model** | Deterministic fake model used in tests (`shared/`) |
| **TOON** | Token-Oriented Object Notation: compact serialisation for LLM context |
| **Virtual threads** | Lightweight JVM threads (Java 21) for cheap blocking I/O |
